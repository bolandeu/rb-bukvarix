
 Usage: bukvarix config get [OPTIONS] {key}

 Получить одно значение конфигурации.

 Example: bukvarix config get cli.min_version

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key      <str>  Ключ конфигурации через точку, например cli.min_version (см. `config        │
│                      list`).                                                                     │
│                      [required]                                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Вывести результат в машиночитаемом формате JSON.                                │
│ --quiet          Подавить второстепенный вывод.                                                  │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
