
 Usage: bukvarix config set [OPTIONS] {key} {value}

 Установить одно (несекретное) значение конфигурации.

 Example: bukvarix config set cli.min_version 0.2.0

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key        <str>  Ключ конфигурации через точку, например cli.min_version (см. `config      │
│                        list`).                                                                   │
│                        [required]                                                                │
│ *    value      <str>  Новое значение (сохраняется как строка). [required]                       │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Вывести результат в машиночитаемом формате JSON.                                │
│ --quiet          Подавить второстепенный вывод.                                                  │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
