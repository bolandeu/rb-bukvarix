
 Usage: bukvarix db import-keywords [OPTIONS] {path}

 Импортировать региональный TSV Bukvarix, заменив текущее содержимое базы.

 Деструктивно: выполняет CREATE OR REPLACE TABLE — существующая таблица
 keywords (и всё, что построили над ней normalize/reindex) пропадает
 после запуска. Сделайте бэкап файла базы заранее (см. AGENTS.md) —
 автоматического бэкапа нет.

 Example: bukvarix db import-keywords msk.tsv --dry-run

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    path      <path>  Путь к TSV с ключевыми словами (phrase\tfreq, без заголовка) [required]   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --confirm          Подтвердить деструктивное действие (обязательно вместе с --non-interactive).  │
│ --dry-run          Показать, что произойдёт, без внесения изменений.                             │
│ --json             Вывести результат в машиночитаемом формате JSON.                              │
│ --quiet            Подавить второстепенный вывод.                                                │
│ --verbose          Вывести дополнительную диагностику.                                           │
│ --help             Show this message and exit.                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
