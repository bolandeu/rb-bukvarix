
 Usage: bukvarix search [OPTIONS] {query}

 Поиск фраз. По умолчанию: частотность самой фразы + список похожих фраз в глубину (порядок слов и
 словоформы не важны) — один вызов, как ввод в Wordstat. Явный --mode для более узкого/буквального
 контроля:

 --mode contains: буквальная подстрока, порядок слов важен
 --mode words: все слова присутствуют, порядок не важен (без лемм)
 --mode prefix: фраза начинается с QUERY
 --mode exact: только единственная каноническая фраза (после дедупа перестановок)
 --mode query: буквальные операторы +слово/-слово (без лемм)
   например "+в москве -недорого"
 --mode scan: то же, что дефолт, но полным сканом без индекса лемм
   (медленно; ищет по подстроке — для сверки с индексом)

 Example: bukvarix search "растаможка авто" --limit 10 --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    query      <str>  Фраза; +слово — обязательное, -слово — исключить. [required]              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --mode           <str>   без флага — умный дефолт (self + похожие фразы, порядок/форма слов не   │
│                          важны, как в Wordstat) | contains | words | prefix | exact | query |    │
│                          scan                                                                    │
│ --limit          <int>   Сколько похожих фраз вернуть. [default: 20]                             │
│ --csv            <path>  Сохранить результаты в CSV вместо печати                                │
│ --json                   Вывести результат в машиночитаемом формате JSON.                        │
│ --quiet                  Подавить второстепенный вывод.                                          │
│ --verbose                Вывести дополнительную диагностику.                                     │
│ --help                   Show this message and exit.                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
