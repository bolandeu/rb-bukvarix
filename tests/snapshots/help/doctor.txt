
 Usage: bukvarix doctor [OPTIONS]

 Проверить готовность окружения и базы данных.

 Всегда завершается с exit 0 — сам отчёт и есть результат; `healthy`
 показывает, прошли ли все проверки.

 Example: bukvarix doctor --json

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json             Вывести результат в машиночитаемом формате JSON.                              │
│ --quiet            Подавить второстепенный вывод.                                                │
│ --verbose          Вывести дополнительную диагностику.                                           │
│ --help             Show this message and exit.                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
