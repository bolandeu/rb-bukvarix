
 Usage: bukvarix freq [OPTIONS] {query}

 Точная частотность одной фразы (порядок слов не важен).

 Example: bukvarix freq "растаможка авто" --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    query      <str>  Фраза, частотность которой нужна. [required]                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json             Вывести результат в машиночитаемом формате JSON.                              │
│ --quiet            Подавить второстепенный вывод.                                                │
│ --verbose          Вывести дополнительную диагностику.                                           │
│ --help             Show this message and exit.                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
