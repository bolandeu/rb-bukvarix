
 Usage: bukvarix freq [OPTIONS] [queries]...

 Точная частотность фраз (порядок слов не важен) — одной или пачкой.

 Ответ всегда один: results по фразе на каждый вход, в порядке ввода, плюс
 источник (source), регион (region, 213 = Москва) и дата данных (data_date;
 null — база импортирована до того, как дату начали сохранять). Фразы нет
 в базе — freq_msk_exact 0 и matched_via null, не ошибка.

 Example: bukvarix freq "доставка грузов из китая" "доставка из китая" --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   queries      <str>  Фразы, точная частотность которых нужна (одна или несколько).              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --input          <str>  Файл с фразами, по одной на строку; '-' — читать из stdin. Добавляется к │
│                         аргументам.                                                              │
│ --json                  Вывести результат в машиночитаемом формате JSON.                         │
│ --quiet                 Подавить второстепенный вывод.                                           │
│ --verbose               Вывести дополнительную диагностику.                                      │
