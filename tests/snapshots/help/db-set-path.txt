
 Usage: bukvarix db set-path [OPTIONS] {path}

 Сохранить путь к файлу базы данных (переопределяется переменной окружения BUKVARIX_DB_PATH).

 Example: bukvarix db set-path /Volumes/Data/bukvarix/rb_bukvarix.duckdb

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    path      <path>  Путь к файлу .duckdb для команд search/freq/stats/db. [required]          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Вывести результат в машиночитаемом формате JSON.                                │
│ --quiet          Подавить второстепенный вывод.                                                  │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
